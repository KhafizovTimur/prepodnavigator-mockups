## Обновление и работа с карточками

Планировщик Windows на компьютере проекта запускает загрузку из [каталога ТИУ](https://timetable.tyuiu.ru/) ежедневно в 05:17 по Москве. Пропущенный запуск выполняется при следующей возможности, когда пользователь вошёл в Windows и есть сеть. Для ручной загрузки выполните `python -m timetable.refresh_pages` из папки рабочего проекта с настроенным доступом Git к репозиторию. Ход загрузки записывается в `.cache/daily-update.log`.

После полного импорта в репозиторий отправляется сжатая база `project/data/schedule.sqlite3.gz`. [GitHub Actions](https://github.com/KhafizovTimur/prepodnavigator-mockups/actions/workflows/schedule.yml) собирает из неё каталог и карточки и публикует их на Pages. При ошибке посетители видят предыдущую версию с её датой загрузки. Графики пересдач из документов кафедр обновляются отдельно.

Кнопка «В избранное» сохраняет преподавателя в текущем браузере. Список доступен на странице поиска. Кнопка «Поделиться карточкой» передаёт ссылку через меню устройства или позволяет её скопировать. Ссылка сохраняет выбранную неделю.
